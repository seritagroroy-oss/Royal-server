Windows-8.1 Live

Windows 8 est une version du système d'exploitation de Microsoft sortie le 26 octobre 2012. Il a introduit une nouvelle interface utilisateur orientée vers les écrans tactiles, appelée « Modern UI » ou « Metro », et a été conçu pour fonctionner aussi bien sur les PC que sur les tablettes. Cette version a apporté des changements majeurs depuis Windows 95, notamment un écran d'accueil plein écran, le support de l'USB 3.0, et une amélioration de la vitesse de démarrage.
